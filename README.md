Этот проект разработан в рамках курса по Django. Он представляет собой базовую структуру интернет-магазина, которая
будет дополняться функциональностью на последующих уроках.

* **Управление зависимостями:** Poetry

* Реализовано наследование от базового шаблона `base.html`.
* Внедрена система подшаблонов (меню вынесено в `inc_main_menu.html`).

**Каталог товаров (ORM):**

* Настроена динамическая выдача списка товаров из БД на главную страницу.

**Карточка товара:**

## Перевод на CBV

Все контроллеры приложения `catalog` переведены с функций на классы (`ListView`, `DetailView`, `TemplateView`).

* **Приложение Блога**:
    * Реализован полный CRUD для блоговых записей на базе CBV.
    * Настроена фильтрация: в списке отображаются только опубликованные статьи.
    * Реализовано автоматическое увеличение счетчика просмотров при открытии статьи.

## Формы

* **CRUD**: Реализованы контроллеры для создания (`CreateView`), редактирования (`UpdateView`) и удаления (`DeleteView`)
  продуктов.
* **Валидация**:
    * **Запрещенные слова**: Настроена проверка полей `название` и `описание`. Система блокирует сохранение, если в
      тексте встречаются слова: *казино, криптовалюта, крипта, биржа, дешево, бесплатно, обман, полиция, радар*.
    * **Цена**: Реализована кастомная проверка `clean_price`, исключающая ввод отрицательной стоимости.
* **Стилизация**: Все формы переведены на использование Bootstrap-классов (`form-control` для текстовых полей и
  `form-check-input` для чекбоксов) через переопределение метода `__init__`.

## Пользователи и авторизация

В проекте реализована продвинутая система управления пользователями с заменой стандартного механизма Django.

* **Кастомная модель пользователя**:
    * Авторизация переведена с `username` на **Email**.
    * Добавлены дополнительные поля: аватар, номер телефона и страна.
    * Настроен кастомный `UserManager` для корректной работы `createsuperuser`.
* **Аутентификация**:
    * Реализован полный цикл: регистрация, вход и выход из системы.
    * Добавлены контроллеры для регистрации (`CreateView`) и редактирования профиля пользователя (`UpdateView`).
* **Интеграция с почтой**:
    * Настроена автоматическая отправка приветственного письма при успешной регистрации.
    * Для разработки используется `Console Email Backend` (вывод писем в терминал).
* **Динамический интерфейс**:
    * Меню сайта (`inc_main_menu.html`) адаптируется под статус пользователя: авторизованным отображается email и кнопка
      выхода, гостям — ссылки на вход и регистрацию.

* **Владелец**: Может редактировать и удалять только свои продукты. При создании продукта владелец назначается
  автоматически.
* **Модератор**:
    * Создана группа «Модератор продуктов» с кастомными правами.
    * Модератор может просматривать любые продукты.
    * Модератор может отменять публикацию (поле `is_published`), но не может менять описание, название или цену (поля
      блокируются в форме).
    * Модератор имеет право на удаление любого продукта.
* **Автоматизация**: Для настройки прав и групп реализована команда `python manage.py fill_groups`.
